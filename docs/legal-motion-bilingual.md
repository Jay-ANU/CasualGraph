# 法务首页动效与中英文界面

## 使用

首次打开 `/` 默认中文，不跟随浏览器的英文设置。`/zh` 和 `/en` 是可直接分享的首页入口。首页导航、登录、会员权限提示以及法务工作台提供「中文 / EN」切换；选择保存在当前浏览器中。

工作台使用 `?lang=en` 或 `?lang=zh-CN`，并保留 `contract` 参数、当前事项、审查设置和未提交输入。切换界面语言不会发起合同修改或重新审查请求。

合同原文、脱敏文本、模型生成的分析及服务端的自由文本保持原样；这不是合同翻译功能。旧研究、图谱和管理业务没有重写。

## 视觉与视频

首页以深绿、暖金和纸张为主视觉，展示法务流程及采购、服务、销售、保密协议的交互示例。示例为静态演示，不是对具体合同的法律意见。

`frontend/public/media/legal-motion.mp4` 为原创六秒无声循环，960 × 800、24 fps、H.264。包含合同纸张、扫描线和轨道光点，搭配界面标签入场及按钮反馈。由 `scripts/render_legal_motion.py` 生成，没有使用合同数据或第三方视频服务。

视频首次进入视野才加载，离开视野或切到其他浏览器标签时暂停。手动暂停保留当前视频帧，并保存暂停偏好；系统「减少动态效果」启用后不加载视频，节流连接默认静态，需主动播放。视频失败使用本地静态封面，不阻塞主要操作。

研究、图谱与管理页面按需加载，避免首页加载这些业务模块。主标题从第一帧即保持可见；深色区域使用独立前景色，不继承全局黑色标题样式。

## 验证

在 `frontend` 下运行：

```sh
npm ci
npm run typecheck
npm run lint
npm test -- --run
npm run build
```

在仓库根目录安装 Playwright 及 Chromium 后运行：

```sh
python scripts/legal_motion_locale_smoke.py
python scripts/legal_ui_smoke.py
python scripts/research_ui_smoke.py
```

浏览器检查采用合成数据和模拟接口，不上传真实合同，不消耗模型额度，不证明模型本身的法律判断质量。测试产物写到 `ui-artifacts`。

覆盖中文默认与语言持久化、视频播放和暂停、离屏暂停、系统动效偏好变更、节流连接、视频失败、深色标题对比度、登录跳转、表单不重建、原文和 API 枚举不变，以及 320 / 390 / 768 / 1024 / 1440 像素布局。保留原法务流程和研究工作台回归。

永久 CI 已加入中英文与动效浏览器检查。生成、传输及一次性验证用的临时文件不属于发布版本。
