# 合同审查首版：外部法律证据 + 数据库公司规范

本模块继承 `claude/legal-agent-product-redesign-tuujqu` 的事项、组织权限、审计和加密能力，不重建私有法规库。

## 工作流

`/agent` 在后端支持 `/legal/capabilities` 时进入合同工作台。后端尚未发布时保留旧工作台，防止前后端错配。`/legal` 是直接入口，`/research` 保留原资料问答；敏感合同应使用法务上传入口，不能使用旧 RAG 上传代替脱敏。

上传 DOCX / 文字 PDF / UTF-8 TXT → 后端本地解析 → 加密保存原件 → 展示脱敏预览、人工补充词 → 人工确认 → 明确我方角色、合同类型、交易日期及外部模型处理授权 → 审查 → 逐条接受/保留原文 → 导出。

原件、代称映射、公司规范、审查状态均加密存储在原 AUTH_DB_PATH 的新增表中。审核意见和公司规范按组织/事项授权；平台管理员不自动获得事项数据。规范只能由组织 owner/admin 编辑。版本快照固定在每轮审查中。审计与相关写入同一事务。未改变既有数据库表或删除历史数据。

## 法规证据

默认 `LEGAL_SEARCH_PROVIDER=auto`：存在 `TAVILY_API_KEY` 时使用 Tavily；否则使用 Bing RSS 公共检索。可显式设为 `tavily`、`bing_rss`，其他值关闭检索。Bing RSS 是尽力而为的兼容通道，不承诺服务等级、可用性、覆盖率或授权商业规模；生产应使用已获授权、经本环境测试的检索服务。

检索仅提交服务端固定的公开法律问题，不发送合同原文、公司名称或公司规范。搜索摘要不作为证据：必须再次抓取允许列表中的政府/法院等 HTTPS 原始页面，检查重定向、大小、类型及网络目标，再提取正文。证据快照保存 URL、时间、正文哈希和选取的原文片段，不作为长期法律知识库。

模型意见中的法源 ID 和引文必须在本轮证据中存在；合同引文必须逐字存在于所指段落。另有一次模型语义复核。原文匹配不等于版本现行、法条适用正确或结论经过专业审核。界面始终显示版本/适用性需核实。来源缺失、引文不符或复核分歧不得自动回写，任务显示部分完成或待确认。未检索到不是没有风险。

目前公开规则覆盖主体效力、交付验收付款、责任免责、解除期限、知识产权/数据、争议与一致性；它们是审查目录，不是已由专业律师签署的法律规则库。每组检查看到完整的脱敏正文及适用公司规则；缺失附件、图片等列为人工复核范围。

## 任务与修改

SQLite 持久检查点与租约避免同一任务重复执行；失败可从已保存批次恢复，外部检索失败会重试。工作线程中断/进程重启后用户从任务恢复，不承诺自动无限重试。权限被撤销或事项归档后停止新的外部调用。人工作决定和规范编辑使用版本校验；同一段落不得同时接受相互覆盖的修改。

DOCX 修改基于原文段落锚点，导出真正的 w:ins/w:del 修订。只支持普通正文/表格段落，复杂域、批注、图片等被拒绝自动改写。保留原文件包及未修改段落，修改段落的细粒度字符格式可能改变。PDF 不进行版式回写，只输出报告和文字修改稿。

导出的原件修订稿会恢复真实信息，Word 删除内容仍在文件内。这不是脱敏副本，不能作为脱敏文件对外分享。首版脱敏只用于外部模型的文本视图，不实现可安全公开的 PDF/Word 全文件脱敏。报告含公司规则和审查意见，分享前也需复核。

## 部署

前端为 Vite；`frontend/vercel.json` 显式覆盖旧 CRA 配置，`/api/*` 代理现有 Fly 后端，SPA 回退不能吞掉 API。可用 `VITE_API_BASE` 覆盖。

Fly 继续使用现有 `DEEPSEEK_API_KEY` 和模型配置。必须有：GitHub Actions secret `FLY_API_TOKEN`、Fly 的强 `JWT_SECRET`、持久 AUTH_DB_PATH，以及稳定的 `REDACTION_KEY`（Fernet）。部署脚本仅在 REDACTION_KEY 不存在时生成并经 stdin 设置；不会打印或覆盖已有密钥。遗失密钥将无法解密既有数据，需由部署管理员安全备份。部署不会读取或输出任何秘密值。

首次启用前用合成合同验证整条链路，再由法务使用标注样本评估漏报、误报、法条适用和修改质量。功能测试通过不是法律准确率证明。

## 验证

`pytest -q tests/test_contract_review_product.py`：解析、脱敏、引文/锚点、租户权限、加密、乐观锁、幂等、恢复、撤销权限、授权门槛；外部模型均模拟。

`python scripts/legal_ui_smoke.py`：构建产物的浏览器操作与移动端检查，使用明确的合成数据和模拟 API，不代表真实模型推理已验证。

`python scripts/legal_retrieval_probe.py`：公开问题的真实网络检索探针，不使用合同或模型额度；输出来源元数据。失败必须保留警告，不能包装成外部检索已验证。
